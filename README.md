## 📌 Project Overview

![Employee Data](./employee-data.png)


The **Excel Employee Management System** is an Excel-based project developed using **Microsoft Excel and VBA (Visual Basic for Applications)**.

The project is designed to store and manage employee information in a structured Excel worksheet. VBA macros are included to provide automation and make employee data management easier.

This project demonstrates how Excel can be combined with VBA to create a simple data management and automation solution.

---

## 🎯 Objectives

The main objectives of this project are:

- To maintain employee information in an organized format.
- To store unique Employee IDs.
- To manage employee names, ages, salaries, and departments.
- To record the date on which employee information is added.
- To use VBA macros for automating Excel operations.
- To demonstrate practical use of Excel VBA for data management.
- To create a simple and user-friendly employee record system.

---

## 🛠️ Technologies Used

The following technologies and tools are used in this project:

| Technology | Purpose |
|---|---|
| Microsoft Excel | Data storage and workbook interface |
| VBA | Automation and macro functionality |
| Excel Macros | Automating operations |
| `.xlsm` | Macro-enabled Excel workbook format |
